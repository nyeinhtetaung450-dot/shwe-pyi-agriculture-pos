Shwe Pyi Agriculture POS PWA Starter
အသုံးပြုပုံ
1. ZIP ကိုဖြည်ပြီး ဖိုင်အားလုံးကို folder တစ်ခုတည်းတွင်ထားပါ။
2. HTTPS hosting (ဥပမာ GitHub Pages) သို့တင်ပါ။
3. Android Chrome ဖြင့် HTTPS URL ကိုဖွင့်ပါ။
4. Chrome menu > Install app / Add to Home screen ကိုနှိပ်ပါ။
5. ပထမအကြိမ် Internet ရှိစဉ်ဖွင့်ပြီးမှ Offline စမ်းပါ။

လုပ်ဆောင်ချက်များ: ပစ္စည်းစာရင်း၊ ကုန်ဝယ်၊ Weighted Average Cost၊ အရောင်း၊ ကုန်ကျစရိတ် snapshot၊ အကြမ်းအမြတ်၊ အသုံးစရိတ်၊ အသားတင်အမြတ်၊ IndexedDB local storage။
သတိ: Google Sheets Sync မပါသေးပါ။ Offline အချိန် Google Sheets သို့မပို့နိုင်ပါ။ ဒေတာသည် Browser/ဖုန်းထဲတွင်သာရှိပြီး Browser data ရှင်းလျှင် ပျောက်နိုင်သည်။ Login, backup, multi-device, barcode, အကြွေး၊ ဘောင်ချာပုံနှိပ်ခြင်း မပါသေးပါ။ လုပ်ငန်းသုံးမတိုင်မီ စမ်းသပ်ဒေတာဖြင့် စစ်ဆေးပါ။
Weighted Average ဥပမာ: လက်ကျန် 10 × 1,000 = 10,000; ထပ်ဝယ် 20 × 1,300 = 26,000; ပျမ်းမျှ = 36,000/30 = 1,200 Ks။ 5 ခုကို 1,600 ဖြင့်ရောင်းလျှင် အကြမ်းအမြတ် 2,000 Ks။
